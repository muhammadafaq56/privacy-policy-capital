# Privacy Policy for Capital Smart English Notes

This repository contains the official, publicly hosted Privacy Policy webpage for the Android app **Capital Smart English Notes** (`com.appixdevelopers.smartenglishnotes`), published by **Appix Developers** in collaboration with **Capital Academy Pasrur**.

---

## 🚀 How to Host on GitHub Pages (to get your Google Play URL)

Follow these simple steps:

### Step 1: Create a New GitHub Repository
1. Go to [GitHub](https://github.com) and log in.
2. Click **New Repository** (or visit https://github.com/new).
3. Name your repository (e.g., `smart-english-notes-privacy-policy` or `privacy-policy`).
4. Keep it **Public** (important: Google Play requires it to be publicly accessible without login).
5. Do **NOT** check "Add a README file" (we already have our files here).
6. Click **Create repository**.

---

### Step 2: Push These Files to GitHub
Open a terminal / command prompt in this folder on your Desktop, then run:

```bash
git init
git add .
git commit -m "Initial Privacy Policy for Capital Smart English Notes"
git branch -M main
git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/smart-english-notes-privacy-policy.git
git push -u origin main
```
*(Replace `<YOUR-GITHUB-USERNAME>` with your actual GitHub username)*

---

### Step 3: Enable GitHub Pages (Free Instant HTTPS Hosting)
1. In your GitHub repository, click on **Settings** (top menu bar).
2. On the left sidebar under "Code and automation", click **Pages**.
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` and folder `/ (root)`.
4. Click **Save**.

---

### Step 4: Copy Your Privacy Policy URL
Within 1-2 minutes, GitHub will show a banner at the top of the Pages settings with your live link:

```
https://<YOUR-GITHUB-USERNAME>.github.io/smart-english-notes-privacy-policy/
```

### Step 5: Paste into Google Play Console
1. Return to your Google Play Console tab (**Dashboard** → **Policy** → **Privacy policy**).
2. Paste your live HTTPS link:  
   `https://<YOUR-GITHUB-USERNAME>.github.io/smart-english-notes-privacy-policy/`
3. Click **Save** at the bottom right.
